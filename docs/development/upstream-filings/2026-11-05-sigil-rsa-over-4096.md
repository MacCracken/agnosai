# sigil: RSA keys over 4096 bits cannot verify

**Found by:** agnosai (2026-11-05, roadmap B16 re-check). **Version:** sigil 3.13.15.

`_rsa_recover_em` refuses `n_len > 512`, and `BN_MAX_LIMBS = 64`. With openssl-made keys, an RSA-4096
public key parses (`n_len` 512) and verifies. An RSA-8192 key parses (`n_len` 1024, since
`rsa_pubkey_from_der` honours the caller's `n_max`), but `rsa_pkcs1v15_verify_sha256` returns 0. sigil's
CHANGELOG 3.6.2 states the RSA ≤ 4096 bound.

**Ask:** raise the bound to 8192 bits, or have `rsa_pubkey_from_der` refuse a key it cannot verify, so a
caller learns at key load instead of at every verify. **agnosai** caps its JWT keys at 4096 bits
(`AGNOSAI_JWT_MAX_MODULUS`, `src/server/auth.cyr`), where the Rust line took 8192.
